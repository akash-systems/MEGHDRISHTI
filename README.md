# 🌐 MEGHDRISHTI

## Environmental Early Warning Mesh Network

MEGHDRISHTI is an AI-powered environmental early warning and disaster monitoring platform designed to monitor, analyse and predict multiple environmental hazards using real-time sensor data, GIS intelligence and AI-based risk analysis.

The platform provides a unified command dashboard for monitoring floods, forest fires, landslides, cyclones, gas leaks, pollution and extreme environmental conditions.

# 🚨 Emergency Monitoring

MEGHDRISHTI provides emergency-oriented controls for simulated disaster scenarios.

The system can simulate events such as:

- Flash Flood
- Landslide
- Node Offline
- Increased Rainfall
- Increased Vibration

This allows users to evaluate how environmental conditions could affect the overall risk level.
